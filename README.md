## ✨ Features & Architecture

- **🪐 Interactive 3D Canvas & WebGL**: Rendered with **Three.js** and `@react-three/fiber`, featuring custom 3D avatar animations, dynamic lighting with RGBELoader environment mapping, and interactive cursor tracking.
- **⚡ GSAP ScrollTrigger & Kinetic Motion**: Smooth pinned horizontal scroll showcase, split-text character animations, magnetic button hover states, and smooth spring physics cursor.
- **💼 Production Project Showcase**: Highlighting 6 full-stack & AI projects with dynamic live demo links, repository buttons, and technology badges.
- **🛣️ Journey & Milestones Timeline**: Visual interactive career roadmap documenting competitive achievements (97th percentile GIAIC, SMIT Final AI Hackathon Winner).
- **📄 Direct PDF Resume Integration**: One-click resume access pointing directly to my downloadable/printable PDF resume.
- **📱 Responsive & Touch-Optimized**: Custom mobile navigation with card counter, swipe-to-scroll carousel, and adaptive glassmorphism layout.

## 💻 Getting Started Locally

### 1. Prerequisites
- [Node.js](https://nodejs.org/) (v18.0.0 or higher)
- [Git](https://git-scm.com/)

### 2. Clone the Repository
```bash
git clone https://github.com/devhasnainraza/Portfolio-Website.git
cd Portfolio-Website
```

### 3. Install Dependencies
```bash
npm install
```

### 4. Run Development Server
```bash
npm run dev
```
Open your browser and navigate to `http://localhost:5173`.

### 5. Build for Production
```bash
npm run build
```
The optimized production bundle will be generated inside the `dist/` folder.
